How to Run Duplicate Detection
1
Stop the backend
Ensure Spring Boot is stopped to avoid database locking. Then run:
cd backend && ./mvnw spring-boot:run --scan-only
2
Review log output
Check the console for any duplicate warnings. The Java tool will report all findings.
3
Backup database
Before any cleanup, create a backup copy:
cp backend/devflow_db.mv.db backend/devflow_db.mv.db.backup
4
Run cleanup
If duplicates are found, run without the scan-only flag:
cd backend && ./mvnw spring-boot:run
Manual SQL Analysis via H2 Console
Table Check Type SQL Query
Vendors Duplicate Names SELECT name, COUNT(*) FROM vendors GROUP BY name HAVING COUNT(*) > 1
Products Duplicate SKUs SELECT name, brand, seller_id, COUNT(*) FROM products GROUP BY name, brand, seller_id HAVING COUNT(*) > 1
Deals Duplicate IDs SELECT id, COUNT(*) FROM deals GROUP BY id HAVING COUNT(*) > 1
Notifications Duplicate IDs SELECT id, COUNT(*) FROM notifications GROUP BY id HAVING COUNT(*) > 1
Quotations Duplicate IDs SELECT id, COUNT(*) FROM quotations GROUP BY id HAVING COUNT(*) > 1
Cart Items Duplicate IDs SELECT id, COUNT(*) FROM cart_items GROUP BY id HAVING COUNT(*) > 1
Orders Duplicate IDs SELECT id, COUNT(*) FROM local_orders GROUP BY id HAVING COUNT(*) > 1
Inventory Duplicate Entries SELECT warehouse_id, product_id, COUNT(*) FROM inventory GROUP BY warehouse_id, product_id HAVING COUNT(*) > 1
